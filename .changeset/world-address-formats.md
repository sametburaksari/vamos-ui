AddressField and `formatAddress` follow each country's address format, for every country: the parts it uses and their order (Germany: street, postal code, city, no state; US: street, city, state, ZIP code; Japan: postal code, prefecture, street; the Emirates: no postal code), what they are called (State, Prefecture, Emirate, County, ZIP code, PIN code, Eircode…), and the postal code pattern, with an example as placeholder, a hint when a code does not fit and upper-casing on blur ("ec1y 8sy" → "EC1Y 8SY"). `required="auto"` uses the country's required parts. `formatAddress` gains `format`, `postal` (capitals where the country wants them) and `latin` (Latin-script order for Japan, China, Korea…), and `@vamos-ui/react/locale-data` exports `loadAddressFormat`, `checkPostalCode` and `validateAddress` for the same rules on the server. The data (Google's address metadata, CC BY 4.0) loads as one 5.5 kB gzip chunk on first use. Countries with a cascading source (Türkiye) keep their province → district pickers; a `fields` list you pass is used as before. Countries without a state line (Germany, France, UK…) no longer show a free-text State / Province field unless `fields` asks for it.
